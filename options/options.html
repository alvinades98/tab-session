Mode Isolasi Utama

Per-Tab: Setiap tab browser dapat memiliki session akun berbeda secara independen meskipun membuka website yang sama.
Per-Domain: Mengganti session akan diterapkan ke seluruh tab pada website tersebut.

Tampilkan badge melayang berisi icon & nama session aktif di pojok kanan bawah setiap halaman website. Nonaktifkan jika ingin menghilangkan tulisan dan icon melayang ini.

Panduan Multi-Session Per-Tab

Cara menjalankan banyak akun secara bersamaan di tab berbeda.

1

Fitur Multi-Session Per Tab

Anda dapat membuka website yang sama (misal: twitter.com) di 2 tab berdampingan: Tab 1 memakai Akun A, Tab 2 memakai Akun B tanpa bentrok!

2

Buka Tab Baru Terisolasi

Di popup ekstensi, klik tombol + Tab Baru pada profil yang diinginkan. Tab baru akan otomatis dibuat dan terhubung ke session tersebut.

3

Klik Kanan (Context Menu)

Klik kanan pada tautan link apa pun -> pilih MultiSession Pro > Buka Link di Tab Session Baru untuk langsung membuka link di profil lain.

4

Indikator Tab Realtime

Ikon ekstensi di pojok kanan atas browser selalu menampilkan singkatan nama dan warna session aktif untuk tab yang sedang Anda lihat.
